# ats book - Offline Story Reader App

`ats book` is a lightweight, modern, and high-performance offline story-reading Android application built with Kotlin and Jetpack Compose.

## Key Features
- **100% Offline Access:** No server or active internet connection required.
- **Rich Story Categories:** Stories organized into Romance, Horror, Mystery, Motivational, and Comedy.
- **Reading Comfort:** Built-in Dark Mode, customizable font sizes, and paper-like UI.
- **Bookmark & Favorites:** Save favorite stories or reading progress locally.
- **Social Sharing:** One-tap option to share story excerpts on social media.

## Tech Stack
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose (Material Design 3)
- **Architecture:** MVVM (Model-View-ViewModel)
- **Local Data Handling:** Local JSON / Text Assets
- **Monetization:** Google AdMob (Banner, Interstitial, Rewarded Ads)
